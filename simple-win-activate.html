Активация Windows

Команды выполняются в стандартной командной строке или PowerShell.

💡
Запускайте терминал только от имени администратора. Если на Windows 10 (сборка 19044.7846) возникает ошибка 0x80041008, предварительно установите внеплановое обновление KB5136493 (сборка 19044.7850) и перезагрузите ПК.
Фикс 0x80041008

Внеплановое обновление KB5136493 (сборка 19044.7850)

Исправляет ошибку 0x80041008 на Windows 10 21H2 / LTSC 2021 x64 (сборка 19044.7846). В открывшейся таблице выберите строку 2026-11 Cumulative Update for Windows 10 Version 21H2 for x64-based Systems (KB5136493) (Windows 10 LTSB, 1190,7 MB) и нажмите Загрузить:

Скачать KB5136493 из Каталога Центра обновления Microsoft Нужная строка: Version 21H2 for x64-based Systems · Windows 10 LTSB · 1190,7 MB → «Загрузить» → клик по ссылке .msu
👁‍🗨
Ожидаемый результат: После установки .msu и перезагрузки в заголовке CMD отобразится версия 10.0.19044.7850.

Активация Microsoft Office

Исправленный метод для решения проблемы "SKU not found".

⚠️
Обязательно: Все команды в этом разделе выполняйте в CMD (Командная строка). В PowerShell они работать не будут.
Шаг 1

Вход в папку установки

Если первая команда не сработает (путь не найден), попробуйте вторую.

⬛ CMD (Черное окно)
cd /d "%ProgramFiles%\Microsoft Office\Office16"
⬛ CMD (Черное окно)
cd /d "%ProgramFiles(x86)%\Microsoft Office\Office16"
👁‍🗨
Ожидаемый результат: Путь в строке изменится на ...\Microsoft Office\Office16>
Шаг 2

Ручная установка лицензий Office 2021 (опционально)

Если ProPlus 2021 Volume ставился напрямую через C2R и уже виден в /dstatus, этот шаг можно пропустить. Иначе выполните все три команды по очереди:

⬛ CMD (Черное окно)
cscript ospp.vbs /inslic:"..\root\Licenses16\ProPlus2021VL_KMS_Client_AE-ppd.xrm-ms"
⬛ CMD (Черное окно)
cscript ospp.vbs /inslic:"..\root\Licenses16\ProPlus2021VL_KMS_Client_AE-ul.xrm-ms"
⬛ CMD (Черное окно)
cscript ospp.vbs /inslic:"..\root\Licenses16\ProPlus2021VL_KMS_Client_AE-ul-oob.xrm-ms"
👁‍🗨
Ожидаемый результат: Строка License installed successfully
Шаг 3

Установка ключа и Активация

1. Установка ключа (Office LTSC Professional Plus 2021):

⬛ CMD (Черное окно)
cscript ospp.vbs /inpkey:FXYTK-NJJ8C-GB6DW-3DYQT-6F7TH
👁‍🗨
Ожидаемый результат: <Product key installation successful>

2. Активация:

⬛ CMD (Черное окно)
cscript ospp.vbs /sethst:kms.digiboy.ir & cscript ospp.vbs /act
👁‍🗨
Ожидаемый результат: <Product activation successful>
Шаг 4

Диагностика и Очистка (Опционально)

Рекомендуется сначала проверить статус, и только при наличии конфликтов удалять ключ.

1. Проверка статуса (показывает все установленные ключи):

⬛ CMD (Черное окно)
cscript ospp.vbs /dstatus
Пример лишней лицензии (ищите подобное):

LICENSE NAME: Office 16, Office16O365HomePremR_Grace edition
LICENSE DESCRIPTION: Office 16, RETAIL(Grace) channel
Last 5 characters of installed product key: KHGM9

2. Удаление ключа KHGM9:

Это стоит выполнять, только если диагностика показала наличие "лишней" лицензии (обычно она подписана как Grace edition).

⬛ CMD (Черное окно)
cscript ospp.vbs /unpkey:KHGM9
👁‍🗨
Ожидаемый результат: <Product key uninstall successful>

Очистка обновлений и кэша

Поиск и удаление накопительных пакетов Windows, устаревших компонентов WinSxS, временных файлов и остатков установки Office.

⚠️
Все команды адаптированы для одного окна CMD (Командная строка) от имени администратора. Запускайте очистку только после установки KB5136493, перезагрузки и проверки активации.
Шаг 1

Поиск забытых пакетов (.msu и дистрибутивы Office)

Аудит диска C:\ на наличие скачанных обновлений и локальных архивов Office C2R (stream.*.dat):

⬛ CMD (Администратор)
dir /s /b /a:-d "C:\*.msu" "C:\stream.x64.*.dat" "C:\stream.x86.*.dat" 2>nul
👁‍🗨
Ожидаемый результат: Список полных путей (включая скрытые папки AppData и ProgramData). Найденные .msu и папки Office\Data\... после установки можно удалить вручную.
Шаг 2

Кэш обновлений Windows

1. Очистка SoftwareDistribution\Download (остановка служб, удаление кэша, запуск обратно):

⬛ CMD (Администратор)
net stop wuauserv & net stop bits & rd /s /q "%windir%\SoftwareDistribution\Download" & md "%windir%\SoftwareDistribution\Download" & net start bits & net start wuauserv

2. Сброс кэша оптимизации доставки (P2P-кэш обновлений):

⬛ CMD → PowerShell (Администратор)
powershell -NoProfile -Command "Delete-DeliveryOptimizationCache -Force"
👁‍🗨
Ожидаемый результат: Службы обновлений перезапущены, загруженные архивы и P2P-кэш очищены.
Шаг 3

Очистка хранилища компонентов (WinSxS)

1. Проверка объёма устаревших копий обновлений:

⬛ CMD (Администратор)
Dism.exe /Online /Cleanup-Image /AnalyzeComponentStore

Вариант 2А — штатная очистка устаревших версий пакетов (выберите 2А или 2Б, не запускайте оба подряд):

⬛ CMD (Администратор)
Dism.exe /Online /Cleanup-Image /StartComponentCleanup

Вариант 2Б — максимальная очистка (включает 2А и закрепляет текущие обновления как базу без возможности их отката):

⬛ CMD (Администратор)
Dism.exe /Online /Cleanup-Image /StartComponentCleanup /ResetBase
👁‍🗨
Ожидаемый результат: Операция успешно завершена (обычно освобождает 2–6 ГБ на диске C:).
Шаг 4

Temp, кэш Office и штатная очистка диска

1. Очистка пользовательского и системного Temp (занятые файлы безопасно пропускаются):

⬛ CMD → PowerShell (Администратор)
powershell -NoProfile -Command "if ($env:TEMP) { Remove-Item (Join-Path $env:TEMP '*') -Recurse -Force -EA SilentlyContinue }; if ($env:windir) { Remove-Item (Join-Path $env:windir 'Temp\*') -Recurse -Force -EA SilentlyContinue }"

2. Удаление кэша обновлений Office x64/x86 (рабочая папка root не затрагивается):

⬛ CMD (Администратор)
for %d in ("%ProgramFiles%" "%ProgramFiles(x86)%") do if exist "%~d\Microsoft Office\Updates\Download" rd /s /q "%~d\Microsoft Office\Updates\Download"

3. Графическая проверка остатков (опционально — нажмите «Очистить системные файлы»):

⬛ CMD (Администратор)
cleanmgr /d C:
👁‍🗨
Ожидаемый результат: Временные файлы и остатки загрузок удалены.
