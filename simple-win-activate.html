Фикс 0x80041008

Внеплановое обновление KB5136493 (сборка 19044.7850)

Исправляет ошибку 0x80041008 на Windows 10 21H2 / LTSC 2021 x64 (сборка 19044.7846). В открывшейся таблице выберите строку 2026-11 Cumulative Update for Windows 10 Version 21H2 for x64-based Systems (KB5136493) (Windows 10 LTSB, 1190,7 MB) и нажмите Загрузить:

Скачать KB5136493 из Каталога Центра обновления Microsoft Нужная строка: Version 21H2 for x64-based Systems · Windows 10 LTSB · 1190,7 MB → «Загрузить» → клик по ссылке .msu
👁‍🗨
Ожидаемый результат: После установки .msu и перезагрузки в заголовке CMD отобразится версия 10.0.19044.7850.

Активация Microsoft Office

Исправленный метод для решения проблемы "SKU not found".

⚠️
Обязательно: Все команды в этом разделе выполняйте в CMD (Командная строка). В PowerShell они работать не будут.
Шаг 1

Вход в папку установки

Если первая команда не сработает (путь не найден), попробуйте вторую.

⬛ CMD (Черное окно)
cd /d "%ProgramFiles%\Microsoft Office\Office16"
⬛ CMD (Черное окно)
cd /d "%ProgramFiles(x86)%\Microsoft Office\Office16"
👁‍🗨
Ожидаемый результат: Путь в строке изменится на ...\Microsoft Office\Office16>
Шаг 2

Ручная установка лицензий Office 2021 (опционально)

Если ProPlus 2021 Volume ставился напрямую через C2R и уже виден в /dstatus, этот шаг можно пропустить. Иначе выполните все три команды по очереди:

⬛ CMD (Черное окно)
cscript ospp.vbs /inslic:"..\root\Licenses16\ProPlus2021VL_KMS_Client_AE-ppd.xrm-ms"
⬛ CMD (Черное окно)
cscript ospp.vbs /inslic:"..\root\Licenses16\ProPlus2021VL_KMS_Client_AE-ul.xrm-ms"
⬛ CMD (Черное окно)
cscript ospp.vbs /inslic:"..\root\Licenses16\ProPlus2021VL_KMS_Client_AE-ul-oob.xrm-ms"
👁‍🗨
Ожидаемый результат: Строка License installed successfully
Шаг 3

Установка ключа и Активация

1. Установка ключа (Office LTSC Professional Plus 2021):

⬛ CMD (Черное окно)
cscript ospp.vbs /inpkey:FXYTK-NJJ8C-GB6DW-3DYQT-6F7TH
👁‍🗨
Ожидаемый результат: <Product key installation successful>

2. Активация:

⬛ CMD (Черное окно)
cscript ospp.vbs /sethst:kms.digiboy.ir & cscript ospp.vbs /act
👁‍🗨
Ожидаемый результат: <Product activation successful>
Шаг 4

Диагностика и Очистка (Опционально)

Рекомендуется сначала проверить статус, и только при наличии конфликтов удалять ключ.

1. Проверка статуса (показывает все установленные ключи):

⬛ CMD (Черное окно)
cscript ospp.vbs /dstatus
Пример лишней лицензии (ищите подобное):

LICENSE NAME: Office 16, Office16O365HomePremR_Grace edition
LICENSE DESCRIPTION: Office 16, RETAIL(Grace) channel
Last 5 characters of installed product key: KHGM9

2. Удаление ключа KHGM9:

Это стоит выполнять, только если диагностика показала наличие "лишней" лицензии (обычно она подписана как Grace edition).

⬛ CMD (Черное окно)
cscript ospp.vbs /unpkey:KHGM9
👁‍🗨
Ожидаемый результат: <Product key uninstall successful>

Очистка обновлений и кэша

Поиск и удаление накопительных пакетов Windows, устаревших компонентов WinSxS, временных файлов и остатков установки Office.

⚠️
Все команды адаптированы для одного окна CMD (Командная строка) от имени администратора. Запускайте очистку только после установки KB5136493, перезагрузки и проверки активации.
Шаг 1

Интерактивный поиск и удаление пакетов (.msu и Office C2R)

Сканирует диск C:\ (кроме Windows), группирует найденные .msu и stream.x*.dat по папкам, показывает общий размер в МБ и по каждой папке спрашивает — удалить пакеты (y/д) или пропустить (Enter):

CMD → PowerShell · Администратор
powershell -NoProfile -Command "& { $r = Get-ChildItem C:\ -Dir -Force -Attributes !ReparsePoint -EA 0 | Where-Object { $_.Name -notin 'Windows','$Recycle.Bin','System Volume Information','Recovery' }; $f = @(Get-ChildItem C:\ -File -Force -EA 0) + @($r | Get-ChildItem -File -Recurse -Force -EA 0) | Where-Object { $_.Name -like '*.msu' -or $_.Name -like 'stream.x*.dat' }; if (-not $f) { Write-Host 'Пакеты не найдены.' -ForegroundColor Yellow; return }; foreach ($g in ($f | Group-Object DirectoryName)) { $mb = [math]::Round(($g.Group | Measure-Object Length -Sum).Sum / 1MB, 1); Write-Host ('--- Папка: ' + $g.Name + ' | Файлов: ' + $g.Count + ' | Размер: ' + $mb + ' MB') -ForegroundColor Cyan; $g.Group | ForEach-Object { Write-Host (' ' + $_.Name + ' (' + [math]::Round($_.Length/1MB,1) + ' MB)') }; if ((Read-Host 'Удалить эти пакеты в папке? [y/N]') -match '^(y|д)$') { $g.Group | Remove-Item -Force -EA 0; Write-Host 'Удалено.' -ForegroundColor Green } else { Write-Host 'Пропущено.' -ForegroundColor DarkGray } } }"
Удаляются только найденные файлы пакетов внутри выбранной папки — остальные файлы в папке (например, в «Загрузках») остаются нетронутыми.
Шаг 2

Интерактивная очистка кэша обновлений Windows

Подсчитывает размер папок SoftwareDistribution\Download и P2P-кэша Delivery Optimization, выводит объём в МБ и по каждому пункту запрашивает подтверждение (при согласии сам останавливает и запускает службы wuauserv и bits):

CMD → PowerShell · Администратор
powershell -NoProfile -Command "& { $d = Join-Path $env:windir 'SoftwareDistribution\Download'; if (Test-Path $d) { $f = @(Get-ChildItem $d -Recurse -File -Force -EA 0); $mb = [math]::Round(($f | Measure-Object Length -Sum).Sum / 1MB, 1); Write-Host ('--- Папка: ' + $d + ' | Файлов: ' + $f.Count + ' | Размер: ' + $mb + ' MB') -ForegroundColor Cyan; if ($f.Count -gt 0 -and (Read-Host 'Остановить службы и очистить кэш обновлений? [y/N]') -match '^(y|д)$') { Stop-Service wuauserv,bits -Force -EA 0; Get-ChildItem $d -Force -EA 0 | Remove-Item -Recurse -Force -EA 0; Start-Service bits,wuauserv -EA 0; Write-Host 'Очищено, службы запущены.' -ForegroundColor Green } else { Write-Host 'Пропущено.' -ForegroundColor DarkGray } }; $do = @((Join-Path $env:windir 'SoftwareDistribution\DeliveryOptimization'),(Join-Path $env:windir 'ServiceProfiles\NetworkService\AppData\Local\Microsoft\Windows\DeliveryOptimization\Cache')) | Where-Object { Test-Path $_ }; $df = @($do | Get-ChildItem -Recurse -File -Force -EA 0); $dmb = [math]::Round(($df | Measure-Object Length -Sum).Sum / 1MB, 1); Write-Host ('--- Delivery Optimization (P2P-кэш) | Файлов: ' + $df.Count + ' | Размер: ' + $dmb + ' MB') -ForegroundColor Cyan; if ($df.Count -gt 0 -and (Read-Host 'Очистить P2P-кэш обновлений? [y/N]') -match '^(y|д)$') { Delete-DeliveryOptimizationCache -Force -EA 0; Write-Host 'Очищено.' -ForegroundColor Green } else { Write-Host 'Пропущено.' -ForegroundColor DarkGray } }"
Ожидаемый результат: Показан реальный вес каждого кэша; после подтверждения архивы удалены, службы обновлений перезапущены.
Шаг 3

Интерактивный анализ и очистка WinSxS (DISM)

Сначала показывает реальный размер резервных копий и рекомендацию DISM, затем предлагает выбрать режим: 1 — штатная очистка, 2 — максимальная (/ResetBase, без отката текущих обновлений), Enter — пропустить:

CMD → PowerShell · Администратор
powershell -NoProfile -Command "& { Dism.exe /Online /Cleanup-Image /AnalyzeComponentStore; $c = Read-Host 'Выберите: [1] Штатная очистка [2] Максимальная (/ResetBase) [Enter] Пропустить'; if ($c -eq '1') { Dism.exe /Online /Cleanup-Image /StartComponentCleanup } elseif ($c -eq '2') { Dism.exe /Online /Cleanup-Image /StartComponentCleanup /ResetBase } else { Write-Host 'Пропущено.' -ForegroundColor DarkGray } }"
Ожидаемый результат: Операция успешно завершена (обычно освобождает 2–6 ГБ на диске C:).
Шаг 4

Интерактивная очистка Temp и кэша Office

1. По очереди проверяет пользовательский Temp, системный Windows\Temp и кэш обновлений Office (x64/x86, папка root не затрагивается), выводит вес каждой папки в МБ и спрашивает подтверждение:

CMD → PowerShell · Администратор
powershell -NoProfile -Command "& { $p = @(); if ($env:TEMP) { $p += $env:TEMP }; if ($env:windir) { $p += (Join-Path $env:windir 'Temp') }; if ($env:ProgramFiles) { $p += (Join-Path $env:ProgramFiles 'Microsoft Office\Updates\Download') }; if (${env:ProgramFiles(x86)}) { $p += (Join-Path ${env:ProgramFiles(x86)} 'Microsoft Office\Updates\Download') }; foreach ($dir in ($p | Select-Object -Unique | Where-Object { Test-Path $_ })) { $f = @(Get-ChildItem $dir -Recurse -File -Force -EA 0); $mb = [math]::Round(($f | Measure-Object Length -Sum).Sum / 1MB, 1); Write-Host ('--- Папка: ' + $dir + ' | Файлов: ' + $f.Count + ' | Размер: ' + $mb + ' MB') -ForegroundColor Cyan; if ($f.Count -eq 0) { Write-Host ' Папка пуста.' -ForegroundColor DarkGray; continue }; if ((Read-Host 'Очистить содержимое папки? [y/N]') -match '^(y|д)$') { Get-ChildItem $dir -Force -EA 0 | Remove-Item -Recurse -Force -EA 0; Write-Host 'Очищено (занятые файлы пропущены).' -ForegroundColor Green } else { Write-Host 'Пропущено.' -ForegroundColor DarkGray } } }"

2. Графическая проверка остатков (опционально — нажмите «Очистить системные файлы»):

CMD · Администратор
cleanmgr /d C:
Ожидаемый результат: По каждой папке виден реальный объём; подтверждённые каталоги очищены без риска затронуть системные пути.
