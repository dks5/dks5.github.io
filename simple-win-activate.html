Очистка обновлений и кэша

Поиск и удаление накопительных пакетов Windows, устаревших компонентов WinSxS, временных файлов и остатков установки Office.

⚠️
Все команды адаптированы для одного окна CMD (Командная строка) от имени администратора. Запускайте очистку только после установки KB5136493, перезагрузки и проверки активации.
Шаг 1

Интерактивный поиск и удаление пакетов (.msu и Office C2R)

Сканирует весь диск C:\ (включая Windows, скрытые и системные каталоги; исключены только защищённые WinSxS и System Volume Information), группирует найденные .msu и stream.x*.dat по папкам, показывает вес и после удаления проверяет реальный результат:

CMD → PowerShell · Администратор
powershell -NoProfile -Command "& { $rp = [IO.FileAttributes]::ReparsePoint; $dirs = @(Get-ChildItem C:\ -Dir -Force -EA 0 | Where-Object { ($_.Attributes -band $rp) -eq 0 -and $_.Name -notin 'Windows','System Volume Information' }); $dirs += @(Get-ChildItem $env:windir -Dir -Force -EA 0 | Where-Object { ($_.Attributes -band $rp) -eq 0 -and $_.Name -ne 'WinSxS' }); $f = @(Get-ChildItem C:\ -File -Force -EA 0) + @(Get-ChildItem $env:windir -File -Force -EA 0) + @($dirs | ForEach-Object { Get-ChildItem -LiteralPath $_.FullName -File -Recurse -Force -EA 0 }) | Where-Object { $_.Name -like '*.msu' -or $_.Name -like 'stream.x*.dat' }; if (-not $f) { Write-Host 'Пакеты не найдены.' -ForegroundColor Yellow; return }; foreach ($g in ($f | Group-Object DirectoryName)) { $mb = [math]::Round(($g.Group | Measure-Object Length -Sum).Sum / 1MB, 1); Write-Host ('--- Папка: ' + $g.Name + ' | Файлов: ' + $g.Count + ' | Размер: ' + $mb + ' MB') -ForegroundColor Cyan; $g.Group | ForEach-Object { Write-Host (' ' + $_.Name + ' (' + [math]::Round($_.Length/1MB,1) + ' MB)') }; if ((Read-Host 'Удалить эти пакеты в папке? [y/N]').Trim() -match '^(y|yes|\u0434|\u0434\u0430)$') { $ok = 0; $fail = 0; foreach ($it in $g.Group) { $err = $null; try { [IO.File]::SetAttributes($it.FullName, 'Normal') } catch {}; Remove-Item -LiteralPath $it.FullName -Force -ErrorVariable err -EA SilentlyContinue; if (Test-Path -LiteralPath $it.FullName) { $fail++; $m = if ($err) { $err[0].Exception.Message } else { 'файл остался на диске' }; Write-Host (' [НЕ УДАЛЕН] ' + $it.Name + ' -> ' + $m) -ForegroundColor Red } else { $ok++ } }; Write-Host ('Итого: удалено ' + $ok + ', не удалось ' + $fail) -ForegroundColor $(if ($fail -eq 0) {'Green'} else {'Yellow'}) } else { Write-Host 'Пропущено.' -ForegroundColor DarkGray } } }"
Удаляются только найденные пакеты внутри выбранной папки. Если файл защищён или занят процессом, скрипт выведет [НЕ УДАЛЕН] с точной причиной ошибки вместо ложного «Удалено».
Шаг 2

Интерактивная очистка кэша обновлений Windows

Подсчитывает размер SoftwareDistribution\Download и P2P-кэша Delivery Optimization, останавливает связанные службы (wuauserv, bits, UsoSvc, DoSvc), выполняет очистку, возвращает службы в исходное состояние и показывает реальный остаток ДО/ПОСЛЕ:

CMD → PowerShell · Администратор
powershell -NoProfile -Command "& { $d = Join-Path $env:windir 'SoftwareDistribution\Download'; if (Test-Path -LiteralPath $d) { $f = @(Get-ChildItem -LiteralPath $d -Recurse -File -Force -EA 0); $mb = [math]::Round(($f | Measure-Object Length -Sum).Sum / 1MB, 1); Write-Host ('--- Папка: ' + $d + ' | Файлов: ' + $f.Count + ' | Размер: ' + $mb + ' MB') -ForegroundColor Cyan; if ($f.Count -gt 0 -and (Read-Host 'Остановить службы и очистить кэш обновлений? [y/N]').Trim() -match '^(y|yes|\u0434|\u0434\u0430)$') { $svcs = @('wuauserv','bits','UsoSvc','DoSvc'); $run = @(Get-Service $svcs -EA 0 | Where-Object { $_.Status -eq 'Running' }); try { Stop-Service $svcs -Force -EA 0; Start-Sleep -Seconds 1; Get-ChildItem -LiteralPath $d -Force -EA 0 | ForEach-Object { Remove-Item -LiteralPath $_.FullName -Recurse -Force -EA SilentlyContinue } } finally { $run | Start-Service -EA 0 }; $af = @(Get-ChildItem -LiteralPath $d -Recurse -File -Force -EA 0); $amb = [math]::Round(($af | Measure-Object Length -Sum).Sum / 1MB, 1); $freed = [math]::Round([math]::Max(0, $mb - $amb), 1); Write-Host ('Освобождено: ' + $freed + ' MB | Осталось: ' + $af.Count + ' файлов (' + $amb + ' MB)') -ForegroundColor $(if ($af.Count -eq 0) {'Green'} else {'Yellow'}) } else { Write-Host 'Пропущено.' -ForegroundColor DarkGray } }; $do = @((Join-Path $env:windir 'SoftwareDistribution\DeliveryOptimization'),(Join-Path $env:windir 'ServiceProfiles\NetworkService\AppData\Local\Microsoft\Windows\DeliveryOptimization\Cache')) | Where-Object { Test-Path -LiteralPath $_ }; $df = @($do | ForEach-Object { Get-ChildItem -LiteralPath $_ -Recurse -File -Force -EA 0 }); $dmb = [math]::Round(($df | Measure-Object Length -Sum).Sum / 1MB, 1); Write-Host ('--- Delivery Optimization (P2P-кэш) | Файлов: ' + $df.Count + ' | Размер: ' + $dmb + ' MB') -ForegroundColor Cyan; if ($df.Count -gt 0 -and (Read-Host 'Очистить P2P-кэш обновлений? [y/N]').Trim() -match '^(y|yes|\u0434|\u0434\u0430)$') { Delete-DeliveryOptimizationCache -Force -EA 0; $rem = @($do | ForEach-Object { Get-ChildItem -LiteralPath $_ -Recurse -File -Force -EA 0 }); if ($rem.Count -gt 0) { $doRun = @(Get-Service DoSvc -EA 0 | Where-Object { $_.Status -eq 'Running' }); try { Stop-Service DoSvc -Force -EA 0; Start-Sleep -Seconds 1; $do | ForEach-Object { Get-ChildItem -LiteralPath $_ -Force -EA 0 | ForEach-Object { Remove-Item -LiteralPath $_.FullName -Recurse -Force -EA SilentlyContinue } } } finally { $doRun | Start-Service -EA 0 } }; $adf = @($do | ForEach-Object { Get-ChildItem -LiteralPath $_ -Recurse -File -Force -EA 0 }); $admb = [math]::Round(($adf | Measure-Object Length -Sum).Sum / 1MB, 1); $dfreed = [math]::Round([math]::Max(0, $dmb - $admb), 1); Write-Host ('Освобождено: ' + $dfreed + ' MB | Осталось: ' + $adf.Count + ' файлов (' + $admb + ' MB)') -ForegroundColor $(if ($adf.Count -eq 0) {'Green'} else {'Yellow'}) } else { Write-Host 'Пропущено.' -ForegroundColor DarkGray } }"
Ожидаемый результат: Показан реальный вес каждого кэша; после подтверждения архивы удалены, службы обновлений перезапущены.
Шаг 3

Интерактивный анализ и очистка WinSxS (DISM)

Сначала показывает реальный размер резервных копий и рекомендацию DISM, затем предлагает выбрать режим: 1 — штатная очистка, 2 — максимальная (/ResetBase, без отката текущих обновлений), Enter — пропустить:

CMD → PowerShell · Администратор
powershell -NoProfile -Command "& { Dism.exe /Online /Cleanup-Image /AnalyzeComponentStore; $c = (Read-Host 'Выберите: [1] Штатная очистка [2] Максимальная (/ResetBase) [Enter] Пропустить').Trim(); if ($c -eq '1') { Dism.exe /Online /Cleanup-Image /StartComponentCleanup } elseif ($c -eq '2') { Dism.exe /Online /Cleanup-Image /StartComponentCleanup /ResetBase } else { Write-Host 'Пропущено.' -ForegroundColor DarkGray } }"
Ожидаемый результат: Операция успешно завершена (обычно освобождает 2–6 ГБ на диске C:).
Шаг 4

Интерактивная очистка Temp и кэша Office

1. По очереди проверяет пользовательский Temp, системный Windows\Temp и кэш обновлений Office (x64/x86, папка root не затрагивается), выводит вес каждой папки в МБ и спрашивает подтверждение:

CMD → PowerShell · Администратор
powershell -NoProfile -Command "& { $p = @(); if ($env:TEMP) { $p += $env:TEMP }; if ($env:windir) { $p += (Join-Path $env:windir 'Temp') }; if ($env:ProgramFiles) { $p += (Join-Path $env:ProgramFiles 'Microsoft Office\Updates\Download') }; if (${env:ProgramFiles(x86)}) { $p += (Join-Path ${env:ProgramFiles(x86)} 'Microsoft Office\Updates\Download') }; foreach ($dir in ($p | Select-Object -Unique | Where-Object { Test-Path -LiteralPath $_ })) { $f = @(Get-ChildItem -LiteralPath $dir -Recurse -File -Force -EA 0); $mb = [math]::Round(($f | Measure-Object Length -Sum).Sum / 1MB, 1); Write-Host ('--- Папка: ' + $dir + ' | Файлов: ' + $f.Count + ' | Размер: ' + $mb + ' MB') -ForegroundColor Cyan; if ($f.Count -eq 0) { Write-Host ' Папка пуста.' -ForegroundColor DarkGray; continue }; if ((Read-Host 'Очистить содержимое папки? [y/N]').Trim() -match '^(y|yes|\u0434|\u0434\u0430)$') { Get-ChildItem -LiteralPath $dir -Force -EA 0 | ForEach-Object { Remove-Item -LiteralPath $_.FullName -Recurse -Force -EA SilentlyContinue }; $af = @(Get-ChildItem -LiteralPath $dir -Recurse -File -Force -EA 0); $amb = [math]::Round(($af | Measure-Object Length -Sum).Sum / 1MB, 1); $freed = [math]::Round([math]::Max(0, $mb - $amb), 1); Write-Host ('Освобождено: ' + $freed + ' MB | Осталось (занято/нет прав): ' + $af.Count + ' файлов (' + $amb + ' MB)') -ForegroundColor $(if ($af.Count -eq 0) {'Green'} else {'Yellow'}) } else { Write-Host 'Пропущено.' -ForegroundColor DarkGray } } }"

2. Графическая проверка остатков (опционально — нажмите «Очистить системные файлы»):

CMD · Администратор
cleanmgr /d C:
Ожидаемый результат: По каждой папке виден реальный объём; подтверждённые каталоги очищены без риска затронуть системные пути.

Управление Windows через RDP

Настройка удалённого рабочего стола на Windows 10 Enterprise и подключение с MacBook через Windows App.

i
Для входа по RDP у учётной записи Windows обязательно должен быть задан пароль. Команды на стороне Windows выполняются в CMD от имени администратора.
Шаг 1

Диагностика Windows: имя ПК, IPv4, пользователь и статус RDP

Выполните на Windows — команда одной строкой покажет имя компьютера, текущего пользователя, локальный IPv4-адрес, профиль сети, статус RDP, NLA и порт:

CMD → PowerShell · Администратор
powershell -NoProfile -Command "& { $rdp = (Get-ItemProperty 'HKLM:\System\CurrentControlSet\Control\Terminal Server').fDenyTSConnections; $nla = (Get-ItemProperty 'HKLM:\System\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp').UserAuthentication; $port = (Get-ItemProperty 'HKLM:\System\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp').PortNumber; $svc = (Get-Service TermService).Status; $ips = (Get-NetIPConfiguration | Where-Object { $_.IPv4DefaultGateway } | ForEach-Object { $_.IPv4Address.IPAddress }) -join ', '; if (-not $ips) { $ips = (Get-NetIPAddress -AddressFamily IPv4 | Where-Object { $_.IPAddress -notlike '127.*' -and $_.IPAddress -notlike '169.254.*' }).IPAddress -join ', ' }; $prof = (Get-NetConnectionProfile | ForEach-Object { $_.InterfaceAlias + ': ' + $_.NetworkCategory }) -join '; '; Write-Host ('Имя ПК: ' + $env:COMPUTERNAME) -ForegroundColor Cyan; Write-Host ('Пользователь: ' + (whoami)) -ForegroundColor Cyan; Write-Host ('IPv4 (LAN): ' + $ips) -ForegroundColor Cyan; Write-Host ('Профиль сети: ' + $prof); Write-Host ('Служба RDP: ' + $svc); Write-Host ('RDP статус: ' + $(if ($rdp -eq 0) {'ВКЛЮЧЕН'} else {'ВЫКЛЮЧЕН'})) -ForegroundColor $(if ($rdp -eq 0) {'Green'} else {'Red'}); Write-Host ('NLA защита: ' + $(if ($nla -eq 1) {'ВКЛЮЧЕНА'} else {'ВЫКЛЮЧЕНА'})); Write-Host ('Порт RDP: ' + $port) }"
Перенесите выведенные значения Имя ПК, IPv4 (LAN), Пользователь и Порт RDP в поля Шага 3. Если строка RDP статус красная (ВЫКЛЮЧЕН), выполните Шаг 2.
Шаг 2

Включение RDP и открытие брандмауэра (если выключен)

Включает RDP в реестре, активирует проверку подлинности на уровне сети (NLA), переводит службу TermService в автозапуск и открывает правила брандмауэра (работает на русской и английской Windows):

CMD → PowerShell · Администратор
powershell -NoProfile -Command "& { Set-ItemProperty 'HKLM:\System\CurrentControlSet\Control\Terminal Server' -Name fDenyTSConnections -Value 0; Set-ItemProperty 'HKLM:\System\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp' -Name UserAuthentication -Value 1; Set-Service TermService -StartupType Automatic; Start-Service TermService; Enable-NetFirewallRule -Name 'RemoteDesktop-UserMode-In-TCP','RemoteDesktop-UserMode-In-UDP'; Write-Host 'RDP включен, NLA активна, порт 3389 (TCP/UDP) открыт в брандмауэре.' -ForegroundColor Green }"
Администраторы получают доступ по RDP автоматически. Для обычного пользователя без прав администратора добавьте его в группу Пользователи удаленного рабочего стола и отключите автопереход ПК в режим сна.
Шаг 3

Переменные подключения и данные для Windows App (MacBook)

Заполните поля данными из Шага 1 — значения автоматически сохраняются в браузере и формируют готовую карточку для копирования:

[ WINDOWS APP · MACBOOK → ADD PC ]
PC name 192.168.1.50
User account → Username .\Admin
Friendly name (опционально) Win10-Corp (LAN)
  1. Откройте Windows App на MacBook → нажмите + (вверху справа) → Add PC.
  2. В поле PC name вставьте скопированный адрес (для LAN рекомендуется статический IP, закреплённый за Windows в DHCP роутера).
  3. В поле Credentials / User account выберите Add Credentials: вставьте Username (префикс .\ гарантирует вход в локальную учётную запись Windows без конфликта с доменом) и введите пароль пользователя Windows.
  4. При желании задайте Friendly name, на вкладке Display включите Optimize for Retina displays, нажмите Add и откройте подключение двойным кликом. При первом входе подтвердите сертификат кнопкой Continue.

Быстрая проверка доступности порта RDP с MacBook (до запуска Windows App):

macOS · Terminal
nc -vz -G 3 192.168.1.50 3389
Ожидаемый результат на macOS: Connection to ... port [tcp/ms-wbt-server] succeeded!
Тест и фикс

Если таймаут: фикс сети/брандмауэра и глубокая диагностика

1. Windows — перевести все сети Public в Private, активировать правила RDP (Domain,Private) и сразу вывести актуальный статус:

CMD → PowerShell · Администратор
powershell -NoProfile -Command "& { Get-NetConnectionProfile | Where-Object { $_.NetworkCategory -eq 'Public' } | Set-NetConnectionProfile -NetworkCategory Private; Set-NetFirewallRule -Name 'RemoteDesktop-UserMode-In-TCP','RemoteDesktop-UserMode-In-UDP' -Enabled True -Profile Domain,Private; Get-NetConnectionProfile | Select-Object InterfaceAlias,NetworkCategory | Format-Table -AutoSize | Out-Host; Get-NetFirewallRule -Name 'RemoteDesktop-UserMode-In-TCP','RemoteDesktop-UserMode-In-UDP' | Select-Object Name,Enabled,Profile,Action | Format-Table -AutoSize | Out-Host }"

2. Windows — полная диагностика (профиль сети, слушающий сокет RDP, общие политики брандмауэра, правила 3389 и сторонние антивирусы/фаерволы):

CMD → PowerShell · Администратор
powershell -NoProfile -Command "& { $p = (Get-ItemProperty 'HKLM:\System\CurrentControlSet\Control\Terminal Server\WinStations\RDP-Tcp').PortNumber; Get-NetConnectionProfile | Select-Object InterfaceAlias,NetworkCategory | Format-Table -AutoSize | Out-Host; Get-NetTCPConnection -LocalPort $p -State Listen -EA 0 | Select-Object LocalAddress,LocalPort,OwningProcess | Format-Table -AutoSize | Out-Host; Get-NetFirewallProfile | Select-Object Name,Enabled,DefaultInboundAction,AllowInboundRules | Format-Table -AutoSize | Out-Host; Get-NetFirewallRule -Name 'RemoteDesktop-UserMode-In-TCP','RemoteDesktop-UserMode-In-UDP' | Select-Object Name,Enabled,Profile,Action | Format-Table -AutoSize | Out-Host; Get-CimInstance -Namespace root/SecurityCenter2 -ClassName FirewallProduct -EA 0 | Select-Object displayName,productState | Format-Table -AutoSize | Out-Host }"

Второй сценарий: подключение извне (Белый IP)

Для прямого доступа из внешней сети действительно требуется белый (публичный) IP-адрес на роутере (статический либо динамический с DDNS). За провайдерским NAT («серый» IP) входящие пакеты до роутера не дойдут.

Вариант А · Белый IP + VPN на роутере (рекомендуется)

На роутере с белым IP поднимается VPN-сервер (WireGuard / OpenVPN / IPSec). MacBook подключается к VPN, попадает во внутреннюю сеть и открывает Windows по локальному IP. Порт 3389 в интернет вообще не публикуется — максимальная безопасность.

Вариант Б · Проброс порта (только как временная мера)

Открытый наружу порт 3389 мгновенно атакуется ботами. Если нужен прямой проброс (Port Forwarding): закрепите статический LAN IP за Windows, выведите наружу нестандартный порт (например, 33890 → 3389), ограничьте доступ на фаерволе роутера белым списком IP-источников и оставьте включённой NLA.

Как только будет выделен белый IP, переключите режим в Шаге 3 на «Извне» (для Варианта Б) либо используйте профиль LAN поверх VPN-туннеля (для Варианта А).
